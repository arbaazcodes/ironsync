## Gmail SMTP setup

The owner requested personal Gmail for initial testing. The saved and verified Supabase configuration is:

| Field | Value |
| --- | --- |
| Sender name | `IronSync` |
| Sender address | Owner's Gmail address |
| Host | `smtp.gmail.com` |
| Port | `465` |
| Username | Same Gmail address |
| Password | A dedicated Google App Password, entered directly by the owner |

1. Open [Google App Passwords](https://myaccount.google.com/apppasswords), verify identity, and create an app password named `IronSync SMTP`. Google requires 2-Step Verification to be enabled.
2. In Supabase → Authentication → Emails → SMTP Settings, enable custom SMTP and enter the fields above. Paste the app password directly into Supabase, then save. Do not use the normal Gmail password, store the app password in the repository, or paste it into chat.
3. Refresh the settings page and verify custom SMTP remains enabled.
4. Run another confirmation/recovery email test and verify the message actually arrives from the configured sender. Keep email confirmation enabled.
5. Before broad public launch, use a transactional provider with a verified sending domain. Supabase warns that personal SMTP providers may have deliverability problems. Review auth email quotas and provider limits without raising them speculatively.

Sources: [Google app passwords](https://support.google.com/mail/answer/185833?hl=en), [Google SMTP server and ports](https://developers.google.com/workspace/gmail/imap/imap-smtp), [Supabase custom SMTP](https://supabase.com/docs/guides/auth/auth-smtp).
